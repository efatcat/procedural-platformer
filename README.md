# Пятиугольный путь

Небольшой браузерный платформер на HTML5 Canvas с процедурной генерацией.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер в корне репозитория:

```bash
python3 -m http.server
```

Затем откройте `http://localhost:8000`.

## Механика

- Жёлтый пятиугольник — игровой персонаж.
- Управление: `A/D` или стрелки влево/вправо; прыжок — `W`, `↑` или `Space`.
- В каждый момент отображаются только пять платформ: текущая, две позади и две впереди. В начале видны стартовая платформа и две справа.
- Расстояние между платформами процедурно выбирается из трёх вариантов: короткое, среднее и длинное.
- Всего в забеге 40 платформ. После достижения каждой следующей платформа становится центральной в окне из пяти.
- `R` создаёт новый случайный забег.
