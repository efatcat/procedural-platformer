# ПЕНТАГОН·40

Видоизменённая версия процедурного платформера в стилистике тёмной футуристической панели.

## Запуск

Откройте `index.html` напрямую или запустите сервер:

```bash
python3 -m http.server
```

## Управление

- `A/D` или `←/→` — движение;
- `W`, `↑` или `Space` — прыжок;
- `P` — пауза;
- `R` — новый случайный забег.

В окне игры отображаются только пять платформ: две позади игрока, текущая и две впереди. При прохождении очередной платформы окно сдвигается, поэтому игрок остаётся третьим. Уровень содержит 40 платформ, а промежутки выбираются из трёх вариантов.
